# TIP Media Intelligence - Design System & Direction (Radar Intelligence Reference)

Dial: ENERGY 2 / RHYTHM 2 / MOTION 2

## Identity & Purpose
- Product: TIP Media Intelligence (PT Technosoft Indo Prima)
- Reference: Scognamiglio1969/radar-intelligence (Open-source Media Intelligence & Command Center)
- Nature: Mission-critical executive early warning, media intelligence, and crisis decision support command center.
- Target Audience: Public sector executives, intelligence analysts, emergency response coordinators, and media monitoring officers.
- Core Values: High signal-to-noise ratio, authoritative, real-time live feeds, transparent risk calculation, human-in-the-loop auditability.

## Typography & Copy Rules
- Sans: `Inter`, system-ui, -apple-system, sans-serif
- Monospace / Metrics: `JetBrains Mono`, `Consolas`, monospace (used for timestamps, coordinates, reference IDs, and exact scores)
- Antislop Copy Rule (R-02): Strictly NO em dash (`—`) in UI copy. Use colon (`:`), comma (`,`), or hyphens (`-`).
- WCAG AA Contrast: Compliant across all surfaces (R-25).
